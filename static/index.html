Mathematical Formulation of K-NN Classification

For a query face feature vector $\mathbf{x} \in \mathbb{R}^{30000}$ and training set $\mathcal{D} = \{(\mathbf{x}_i, y_i)\}_{i=1}^N$:

$$d(\mathbf{x}, \mathbf{x}_i) = \left(\sum_{j=1}^{30000} |x_j - x_{i,j}|^2\right)^{\frac{1}{2}}, \quad \hat{y} = \arg\max_{c \in \mathcal{C}} \sum_{i \in \mathcal{N}_k(\mathbf{x}), y_i = c} \frac{1}{d(\mathbf{x}, \mathbf{x}_i) + \epsilon}$$
